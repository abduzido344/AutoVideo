# Painel v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar o painel escuro do M1 por um painel claro e limpo no estilo Kimi. Ele tem uma sidebar de projetos, um compositor "Novo vídeo" e um workspace por job, com player, barra de etapas, transcrição ou timeline, abas de detalhe e uma caixa de aprovação.

**Architecture:**
- **Backend:** o FastAPI ganha três dados novos. São `GET /api/recipe-info` e `GET /api/doctor` (em cache) e campos extras em `GET /api/jobs/{id}`.
- **Frontend:** continua React/Vite/shadcn/Kobra, sem router e sem lib de estado.
  - A rota vem do hash (`#/`, `#/p/<id>`) e os dados vêm de polling de 3 s num hook `usePoll`.
  - A lógica pura (formatação, rotas, montagem do FormData, transcrição, faixas da timeline) fica em `web/src/lib/*.ts`, testada com Vitest.
  - Os componentes de tela ficam em `web/src/components` e `web/src/pages`, com testes de componente no Testing Library.

**Tech Stack:** Python 3.13 + FastAPI + pytest. React 19 + Vite 8 + Tailwind v4 + shadcn (`sidebar`, `switch`, `dropdown-menu`) + Kobra (`video`, `sound`), `react-markdown`, Vitest + jsdom + @testing-library/react.

**Spec:** `docs/superpowers/specs/2026-10-15-painel-v2-design.md`. O visual aprovado está em https://claude.ai/artifact/FkqJjVrskAZoL15JgLWxnu.

## Global Constraints

- **Ordem de busca de componentes:** antes de escrever qualquer componente de UI, procure um pronto na ordem Kobra → shadcn base → outros registries (`docs/ui-components.md`). Se escrever à mão, registre o componente nesse doc.
- **Tema:** um só, claro. Tokens: shell `#F7F7F7`; cartão `#FFFFFF` com borda `#EDEDED`; texto `#1F1F1F`/`#6B6B6B`/`#8A8A8A`; bordas `#E6E6E6`/`#EDEDED`; superfícies `#F5F5F5`/`#F3F3F3`/`#ECECEC`.
- **Cores de ação e estado:** ação primária `#111111` com texto branco; estado azul `#2F6BFF`, verde `#22A06B`, vermelho `#C9372C`.
- **Fonte:** Inter (`@fontsource-variable/inter`, já instalada). Números e tempos em `ui-monospace`.
- **Navegação:** `#/` é Novo vídeo e `#/p/<id>` é o workspace. Polling a cada 3 s, sem SSE.
- **Servidor:** só em 127.0.0.1, com as checagens de Host/Origin. Não há login. Nenhuma dependência Python nova.
- **Dependências do frontend:** as únicas novas são `react-markdown` e, em dev, `vitest`, `jsdom`, `@testing-library/react` e `@testing-library/user-event`. Sem router, sem lib de estado.
- **Texto da interface:** em pt-BR.
- **URLs de mídia:** todo `src`/`href` de mídia dos projetos é montado por `assetUrl()`, que codifica cada segmento, porque nomes têm espaço, acento e `#`.

## Review Focus

1. **Nome de projeto ou mídia com espaço, acento ou `#`.** O player e o download têm que abrir o arquivo certo. Teste: `assetUrl` na Task 2.
2. **Polling de 3 s com o usuário digitando o feedback.** O texto não pode sumir. Teste: `ActionBox` mantém o texto ao re-renderizar com um job atualizado (Task 5).
3. **Roteiro em arquivo e texto digitado ao mesmo tempo.** Nada se perde: o texto é anexado ao roteiro. Teste: `buildForm` na Task 4.
4. **Doctor lento ou servidor offline.** A home continua usável, mostrando "Verificando…" ou "Falta: …". Teste: `doctorText` na Task 2 e o fallback de erro do App na Task 3.
5. **`timeline.json` escrito por LLM, com itens além do fim ou sem as listas opcionais.** A timeline renderiza com os itens dentro de 0–100%, sem quebrar. Teste: `timelineTracks` na Task 6.

import type { Doctor } from "@/api"

export const STAGE_LABEL: Record<string, string> = {
  ingest: "Recebendo os arquivos", clean: "Limpando o áudio", transcribe: "Transcrevendo", analyze: "Analisando",
  director: "Diretor escrevendo o brief", gate1: "Aprovar o brief", copywriter: "Copywriter escolhendo os takes",
  plan: "Planejando os cortes", designer: "Designer criando o estilo", editor: "Editor montando a timeline",
  render: "Renderizando", gate2: "Aprovar o corte", post: "Gerando o post",
}

export type Tone = "blue" | "gray" | "green" | "red"
export const TONE_TEXT: Record<Tone, string> = {
  blue: "text-info", gray: "text-muted-foreground", green: "text-success", red: "text-destructive",
}

export function projectName(projectDir: string): string {
  const base = projectDir.split(/[\\/]/).filter(Boolean).pop() ?? projectDir
  const name = base.replace(/^\d{8}-\d{6}-/, "").replace(/-/g, " ").trim() || base
  return name.charAt(0).toUpperCase() + name.slice(1)
}

export function statusInfo(job: { status: string; error: string }): { label: string; tone: Tone } {
  switch (job.status) {
    case "awaiting_approval": return { label: "aprovar", tone: "blue" }
    case "completed": return { label: "pronto", tone: "green" }
    case "failed": return { label: job.error?.includes("interrompido") ? "interrompido" : "falhou", tone: "red" }
    default: return { label: "rodando", tone: "gray" }
  }
}

export const totalCost = (ds: { cost_usd: number | null }[]) => ds.reduce((s, d) => s + (d.cost_usd ?? 0), 0)
export const money = (v: number) => `$${v.toFixed(2).replace(".", ",")}`

export function clock(s: number): string {
  const t = Math.max(0, Math.floor(s))
  return `${String(Math.floor(t / 60)).padStart(2, "0")}:${String(t % 60).padStart(2, "0")}`
}

export function assetUrl(rel: string, path: string, bust?: number): string {
  const enc = [...rel.split("/"), ...path.split("/")].map(encodeURIComponent).join("/")
  return `/projects/${enc}${bust ? `?t=${bust}` : ""}`
}

export function stageIndex(job: { status: string; stage: string }, stages: string[]): number {
  return job.status === "completed" ? stages.length : Math.max(0, stages.indexOf(job.stage))
}

export function appendChip(text: string, chip: string): string {
  const t = text.trim()
  if (t.includes(chip)) return t
  return t ? `${t}, ${chip}` : chip
}

export function doctorText(d: Doctor | null): { ok: boolean | null; text: string } {
  if (!d) return { ok: null, text: "Verificando o sistema…" }
  const bad = d.checks.find((c) => !c.ok)
  if (!bad) return { ok: true, text: "Tudo pronto · Claude, HyperFrames, FFmpeg e Parakeet ok" }
  return { ok: false, text: `Falta: ${bad.name}${bad.detail ? ` — ${bad.detail}` : ""}` }
}

export function playerClass(aspect: string | null): string {
  if (aspect === "9:16") return "aspect-[9/16] h-[60vh] w-auto"
  if (aspect === "1:1") return "aspect-square h-[60vh] w-auto"
  return "aspect-video w-full"
}

import { useEffect, useState } from "react"

export type Route = { name: "new" } | { name: "project"; id: number }

export function parseHash(hash: string): Route {
  const m = /^#\/p\/(\d+)$/.exec(hash)
  return m ? { name: "project", id: Number(m[1]) } : { name: "new" }
}

export function go(r: Route): void {
  location.hash = r.name === "project" ? `#/p/${r.id}` : "#/"
}

export function useRoute(): Route {
  const [route, setRoute] = useState(() => parseHash(location.hash))
  useEffect(() => {
    const on = () => setRoute(parseHash(location.hash))
    addEventListener("hashchange", on)
    return () => removeEventListener("hashchange", on)
  }, [])
  return route
}

import { useCallback, useEffect, useRef, useState } from "react"

// ponytail: polling fixo; SSE se 3 s ficar lento demais
export function usePoll<T>(fn: () => Promise<T>, ms = 3000) {
  const [data, setData] = useState<T | null>(null)
  const [error, setError] = useState(false)
  const fnRef = useRef(fn)
  useEffect(() => { fnRef.current = fn })
  const refresh = useCallback(() => {
    fnRef.current().then((d) => { setData(d); setError(false) }, () => setError(true))
  }, [])
  useEffect(() => {
    refresh()
    const t = setInterval(refresh, ms)
    return () => clearInterval(t)
  }, [refresh, ms])
  return { data, error, refresh }
}

export type Attachments = { videos: File[]; script: File | null; assets: File[] }
export const EMPTY: Attachments = { videos: [], script: null, assets: [] }

const VIDEO_EXT = /\.(mp4|mov|m4v|webm|mkv|avi)$/i
const SCRIPT_EXT = /\.(md|txt)$/i

export function classify(files: File[], prev: Attachments): Attachments {
  const out: Attachments = { videos: [...prev.videos], script: prev.script, assets: [...prev.assets] }
  for (const f of files) {
    if (f.type.startsWith("video/") || VIDEO_EXT.test(f.name)) out.videos.push(f)
    else if (SCRIPT_EXT.test(f.name)) out.script = f
    else out.assets.push(f)
  }
  return out
}

export function removeFile(a: Attachments, f: File): Attachments {
  return { videos: a.videos.filter((x) => x !== f), script: a.script === f ? null : a.script, assets: a.assets.filter((x) => x !== f) }
}

// texto digitado vira roteiro; com arquivo de roteiro, o texto entra no fim como "## Pedido"
export async function buildForm(a: Attachments, text: string, recipe: string, approve: boolean): Promise<FormData> {
  const fd = new FormData()
  fd.set("recipe", recipe)
  fd.set("auto", approve ? "false" : "true")
  a.videos.forEach((v) => fd.append("videos", v))
  const note = text.trim()
  let script = a.script
  if (note) {
    const body = script ? `${await script.text()}\n\n## Pedido\n${note}\n` : note
    script = new File([body], script?.name ?? "roteiro.md", { type: "text/markdown" })
  }
  if (script) fd.set("script", script)
  a.assets.forEach((x) => fd.append("assets", x))
  return fd
}

import type { Word } from "@/api"

export type Token = { text: string; cut: boolean; start: number }

// fillers = sugestões da análise; pausa maior que gapS aparece como "silêncio N s" (também sai no corte)
export function tokens(t: { words: Word[]; fillers: number[] }, gapS = 1.0): Token[] {
  const fillers = new Set(t.fillers)
  const out: Token[] = []
  t.words.forEach((w, i) => {
    const prev = t.words[i - 1]
    if (prev && w.start - prev.end > gapS) {
      out.push({ text: `silêncio ${(w.start - prev.end).toFixed(1).replace(".", ",")} s`, cut: true, start: prev.end })
    }
    out.push({ text: w.text, cut: fillers.has(i), start: w.start })
  })
  return out
}

import type { TimelineJSON } from "@/api"

export type Clip = { left: number; width: number; label: string; at: number }
export type Track = { key: "video" | "zoom" | "overlay" | "captions" | "music" | "sfx"; name: string; clips: Clip[] }

const MIN_W = 0.6 // % mínimo para um item curto continuar clicável

export const duration = (t: TimelineJSON) => t.segments.reduce((s, x) => s + (x.out - x.in), 0)
const stem = (p: string) => (p.split("/").pop() ?? p).replace(/\.[^.]+$/, "")

export function timelineTracks(t: TimelineJSON): Track[] {
  const T = duration(t) || 1
  const clip = (start: number, dur: number, label: string): Clip => {
    const a = Math.min(Math.max(start, 0), T)
    const b = Math.min(Math.max(start + dur, a), T)
    // multiplica antes de dividir: (4/10)*100 dá 40.00000000000001, (4*100)/10 dá 40
    const width = Math.max(((b - a) * 100) / T, MIN_W)
    return { left: Math.min((a * 100) / T, 100 - width), width, label, at: a }
  }
  let off = 0
  const video = t.segments.map((s) => { const c = clip(off, s.out - s.in, ""); off += s.out - s.in; return c })
  return [
    { key: "video", name: "Vídeo", clips: video },
    { key: "zoom", name: "Zoom", clips: (t.zooms ?? []).map((z) =>
      clip(z.at, z.dur, z.kind === "push" ? `${Math.round((z.scale ?? 1.12) * 100)}%` : "punch")) },
    { key: "overlay", name: "Overlays", clips: [
      ...(t.overlays ?? []).map((o) => clip(o.start, o.dur, stem(o.src))),
      ...(t.broll ?? []).map((b) => clip(b.start, b.dur, "b-roll"))] },
    { key: "captions", name: "Legendas", clips: t.captions === false ? [] : [clip(0, T, "legendas")] },
    { key: "music", name: "Música", clips: t.music ? [clip(0, T, stem(t.music.src))] : [] },
    { key: "sfx", name: "SFX", clips: (t.sfx ?? []).map((s) => clip(s.at, s.dur ?? 1, stem(s.src))) },
  ]
}
